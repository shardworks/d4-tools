# d4-tooling

Tools for exploring and analyzing Diablo IV builds.

## Purpose

This project is a workspace for building utilities that help reason about character builds in Diablo IV — evaluating skill synergies, gear affixes, paragon boards, and damage calculations across classes and seasons.

## Goals

- Parse and model the D4 build space (skills, aspects, uniques, paragon glyphs)
- Analyze build tradeoffs: survivability vs throughput, cooldown vs resource
- Identify dominant and underexplored build paths
- Support theorycraft with data, not just intuition

## Status

Early exploration. Nothing here is stable yet.
